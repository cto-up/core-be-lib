# core-be-lib documentation

repository, which every product mounts at `docs/platform-docs/`:

- Authentication, sessions, MFA, tenancy and roles:
  <https://gitlab.com/ctoup/platform-docs/-/tree/main/auth>
- Everything else core owns (API tokens, file storage, request logging) and
  core's own ADRs (`libs/core/adr/`, cited as "core ADR 001"):
  <https://gitlab.com/ctoup/platform-docs/-/tree/main/libs/core>

Change those pages there, not here.
